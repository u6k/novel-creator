# 脚本量産用プロンプトセット README

## 目的
このプロンプトセットは、**単発で脚本を書くための道具ではなく**、複数の脚本企画を半自動で設計・比較・選抜・改善するための運用基盤です。

## 想定利用者
- 編集者・企画者
- 脚本制作オペレーター
- 個人クリエイターの制作管理者
- 量産体制を構築したい創作チーム

## 使い方（基本）
1. `00_variables.md` で案件変数を定義する。
2. `01`〜`07` で企画からシーン設計まで固める。
3. `08` で脚本ドラフト化する（設計情報必須）。
4. `09` で改稿、`10` で品質管理を実施する。
5. 必要に応じて `11` `13` でジャンル差分・台詞/ト書きスタイル差分を適用する。
6. 複数案件同時運用では `12` を併用する。

## 推奨ワークフロー
- **探索フェーズ**: 00 → 01 → 12（比較・選別）
- **設計フェーズ**: 02 → 03 → 04 → 05 → 06 → 07
- **脚本化フェーズ**: 08 → 09
- **検収フェーズ**: 10
- **拡張フェーズ**: 11 / 13 / 14

## 工程一覧（何をするか一目で分かる版）

| 工程 | ファイル | ここでやること（要点） | 主な出力 | 次へ進む判断 |
|---|---|---|---|---|
| 0 | `00_variables.md` | 案件共通変数を必須/任意で定義し、TBDを分離する | `PROJECT_VARIABLES` / `TBD_LIST` | 必須変数が埋まり、禁止要素が明確か |
| 1 | `01_concept_generation.md` | 複数の企画案を生成し、差別化軸を明示する | 企画候補一覧（ログライン/売り/差別化） | 類似案が除去できているか |
| 2 | `02_theme_and_premise.md` | テーマを人物の選択と対立に落とす | 中心問い/誤信/到達認識/感情弧 | 抽象語で止まらず行動レベル化できたか |
| 3 | `03_worldbuilding.md` | 世界設定を「制約」として設計する | 物語制約リスト/設定運用ルール | 設定が因果に効いているか |
| 4 | `04_character_design.md` | 役割別キャラクターを欲求・恐れ・変化で定義する | キャラ設計票/関係変化マップ | テンプレ人物化を回避できたか |
| 5 | `05_plot_design.md` | 発端〜結末まで因果でつなぐ全体設計 | 幕/転換点/危機/結末のプロット | ご都合主義チェックを通過したか |
| 6 | `06_outline.md` | シーケンス（または話単位）構成を決める | シーケンス一覧/各役割/フック | 中だるみ指標が基準内か |
| 7 | `07_scene_design.md` | 各シーンの目的・対立・情報開示を定義する | シーンカード群 | 説明だけのシーンが除去できたか |
| 8 | `08_drafting.md` | 設計IDを参照しながら脚本ドラフト化する | 脚本ドラフト（台詞/ト書き） | 設計逸脱がないか |
| 9 | `09_revision.md` | 初稿の冗長・不整合・弱点を修正する | 改稿版/修正ログ | 修正優先度順に主要欠陥を解消したか |
| 10 | `10_quality_control.md` | 品質を点数化し、改善優先度を付ける | QCスコア表/改善バックログ | 合格閾値に達したか |
| 11 | `11_genre_adapters.md` | ジャンル別の強化点と禁則を適用する | ジャンル補正指示 | ジャンル記号依存が過多でないか |
| 12 | `12_batch_production.md` | 複数案件の比較・選抜・重複検知を行う | バッチ比較表/採用候補 | 上位案の採用理由が明文化されているか |
| 13 | `13_style_controls.md` | 台詞/ト書きの語り口を制御する | スタイル設定シート | 可読性と差別化が両立しているか |
| 14 | `14_operator_guide.md` | 人間オペレーターの判断タイミングを決める | 運用手順/判断ゲート | 工程停止・戻し判断が可能か |
| 15 | `15_example_run.md` | 00〜14の連動例を小規模で確認する | サンプル運用ログ | 実運用フローを再現できるか |

## 各ファイルの役割（索引）
- `00_variables.md`: 全工程共通の入力変数定義
- `01_concept_generation.md`: 企画案の多案生成
- `02_theme_and_premise.md`: テーマと心理駆動設計
- `03_worldbuilding.md`: 制約として機能する世界観設計
- `04_character_design.md`: 人物設計と関係構造
- `05_plot_design.md`: 全体プロットの因果設計
- `06_outline.md`: シーケンス構成設計
- `07_scene_design.md`: シーン単位の機能設計
- `08_drafting.md`: 設計済み情報を反映した脚本ドラフト生成
- `09_revision.md`: 改稿
- `10_quality_control.md`: 品質監査と優先修正
- `11_genre_adapters.md`: ジャンル差分
- `12_batch_production.md`: バッチ運用
- `13_style_controls.md`: 台詞/ト書きスタイル制御
- `14_operator_guide.md`: オペレーター運用手順
- `15_example_run.md`: 連動サンプル

## バッチ運用時の使い分け
- 同時に10案以上扱う場合: `01` + `12` を中核にし、上位案のみ `02` 以降へ進める。
- シリーズ候補探索: `00` のシリーズ性変数を固定し、`01` で差分のみ変える。
- スタイルA/Bテスト: 設計を固定し `13` のみ差し替え比較する。
